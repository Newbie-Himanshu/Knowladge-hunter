## 🙋‍♂️ About Me

I build full-stack web applications with a focus on **India-native e-commerce**.  
My current flagship project — **The Storefront** — is an open-source, self-hosted commerce platform built specifically for Indian artisans: UPI-first payments, COD with OTP fraud prevention, Shiprocket logistics, and Devanagari-ready typography.

- 🔭 Currently building [**The Storefront**](https://github.com/Newbie-Himanshu/frontend) — open e-commerce for Indian artisans
- 🛠️ Stack of choice: **Next.js 15 · MedusaJS v2 · TypeScript · Tailwind CSS · PostgreSQL · Redis**
- 🇮🇳 Passionate about making technology accessible to small & independent sellers in India
- 💡 Interested in headless commerce, serverless architecture, and developer tooling
- 📫 Reach me via [GitHub](https://github.com/Newbie-Himanshu) or open an issue on any of my repos

## 🚀 Featured Projects

### 🛕 The Storefront — Open E-Commerce for Indian Artisans

> India's first open-source, self-hosted e-commerce platform built for weavers, potters, and handcraft sellers.

| Layer | Repo | Description |
|:---|:---|:---|
| 🎨 **Frontend** | [Newbie-Himanshu/frontend](https://github.com/Newbie-Himanshu/frontend) | Next.js 15 storefront — product catalogue, cart, checkout, accounts |
| ⚙️ **Backend** | [Newbie-Himanshu/backend](https://github.com/Newbie-Himanshu/backend) | MedusaJS v2 marketplace — custom Indian commerce modules |

**What makes it India-first:**

| Feature | Detail |
|:---|:---|
| 🏦 **UPI Payments** | Razorpay UPI — India's #1 payment rail, integrated natively |
| 📦 **COD + OTP** | Cash on Delivery with OTP fraud prevention (Twilio) |
| 🚛 **Shiprocket** | India's largest D2C logistics network, real-time tracking |
| ₹ **INR & GST** | ₹ currency, paisa precision, GST-inclusive display pricing |
| 🔤 **Devanagari fonts** | Tiro Devanagari Hindi — authentic Hindi product names |
| 🔒 **Self-hosted** | Your data, your server, zero SaaS lock-in |
